What it does

What Skyward Pragma gives the operation.

Governed actions

Before every action an agent reads the ontology: what each object means, which actions are allowed and who must approve them.

A fleet with one job each

Agents that watch, triage, gather evidence, maintain, guard service levels and audit, on their own schedules, from every half hour to once a week.

Rules that travel

Every agent in a fleet carries the same hard rules, enforced on every run, so none of them closes an alert or deletes a record on its own.

Self improving memory

One switch per workflow. A separate judge grades each run against the workflow's own instructions, the workflow writes a lesson, and the next run starts with its best ones.

In depth

Why AI bolted onto software does not compound

Most enterprise AI is an agent layered on someone else's software, reasoning on someone else's model. Every exception it resolves teaches the vendor. Skyward Pragma turns that around: the agents run inside the customer's boundary, on models the customer controls, over an ontology the customer owns, so every run leaves the organisation a little smarter.

The right layer for every decision

Where the ontology already governs a decision, the rule is applied the same way every time. An exception that needs judgment goes to the model, reasoning over the ontology and citing what it read. A decision that should not be delegated goes to a named approver, inside the workflow they already use.

The model is a component

Open weight frontier models run on the customer's own hardware. When a better one is released it is swapped in, and the ontology, the memory and the workflows carry over. What the agents did can be audited inside the organisation, not taken on a vendor's word.

Where it runs

On premises, in a private cloud or dedicated VPC, or fully air gapped. The boundary is set during scoping to match the customer's compliance posture.

Questions

Questions about Skyward Pragma.

How does Skyward Pragma improve itself?

Turn self improving memory on for a workflow. After each run a judge grades the work against the workflow's own instructions, the workflow writes a lesson, and the next run starts with its best lessons.

Does it train a model on our data?

Skyward Pragma improves the context the model reasons over, kept as lessons in the customer's own memory. Training the weights themselves is Skyward Engram's job, also inside the customer's boundary.

Can it work with the agents we already have?

In most cases. Agents that can move inside the boundary are moved; the rest are connected to the ontology as a context source while the move is planned.
